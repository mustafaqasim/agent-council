# Agent Council

Use the right AI model for each part of a task, without leaving your chat.

Agent Council helps Codex and Claude Code decide when to do work in the main chat, send a clear subtask to another model, or add independent review when the work is risky. The main agent keeps control of the task and explains each delegation. It works for coding, research, analysis, strategy, business planning, documents, and reviews.

This folder is the installable plugin. The repository root is a marketplace. Version 0.9.0 includes portable metadata and host compatibility manifests; directory acceptance and fresh native qualification remain pending. Native delegation requires supported host tools and model access. Local helpers require Python 3 and Bash. Optional Compound Engineering integration is not required.

The skill loads additional policy only for the selected route. Decision tracing is opt-in, local, and contains bounded metadata rather than prompt or response text. The update checker never installs updates. Native eval commands must use `--no-publish`; local tests do not prove host execution or directory acceptance.
